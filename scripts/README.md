# RunIT local scripts

Not deployed with the app. For development, pitch recording, and one-off tests.

| Script | Purpose |
|--------|---------|
| `simulate.js` | Puppeteer walkthrough of production demo (pitch video capture) |
| `scratch_test.js` | Quick You.com API smoke test |
| `voiceover/` | TTS segment files and Python generators for pitch audio |

Run from repo root, e.g. `node scripts/simulate.js`.
